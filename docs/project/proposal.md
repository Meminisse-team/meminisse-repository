# Initial project proposal

[Meminisse initial project proposal](meminisse-proposal.pdf) records the original goals and planned architecture.
Some implementation decisions evolved during development: photo analysis now uses Azure Vision, while the proposal describes Upstage Document Parse. PWA and Web Speech API support in the proposal describe planned capabilities, not the current implementation.

For the current storage architecture, see [Gateway architecture](../architecture/gateways.md) and [Security](../architecture/security.md).
